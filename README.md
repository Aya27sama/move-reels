# Move Reels — фирменный Remotion-шаблон

Постоянный проект для монтажа Instagram Reels психолога в формате 1080×1920, 30 fps.

## Уже настроено

- монтаж исходника по смысловым сегментам через `src/edit-plan.ts`;
- аккуратные jump cuts и управляемые punch-in 103–112%;
- субтитры типа `Caption` в `src/captions.ts`;
- safe zones Instagram: текст отступает от правого интерфейса и нижней панели;
- палитра: olive `#707554`, terracotta `#B6654A`, ivory `#F3EBDD`;
- Cormorant Garamond для субтитров и Forum для акцентов;
- H.264/AAC рендер высокого качества.

## TT Carvist

Шрифт намеренно не скачивается из неофициальных источников. Добавьте лицензионный файл в
`public/fonts/TT-Carvist.otf` или `public/fonts/TT-Carvist.ttf`.
После этого Codex подключит его через `@remotion/fonts`. Пока для крупных акцентов используется Forum.

## Один раз: окружение Codex

Выберите этот репозиторий в Codex Cloud и создайте environment. Setup command:

```bash
npm install
```

В настройках окружения разрешите интернет-доступ, чтобы Codex мог скачать исходник по публичной ссылке.

## Для каждого нового ролика

1. Загрузите исходник в Dropbox или другое облако.
2. Создайте ссылку, доступную без авторизации.
3. В новом задании Codex попросите:
   - скачать файл как `public/source.mov`;
   - проверить дорожки через `ffprobe`;
   - транскрибировать русскую речь с таймкодами;
   - обновить `src/edit-plan.ts`, `src/captions.ts` и смысловые акценты;
   - проверить контрольные кадры и звук;
   - выполнить `npm run render`;
   - вернуть `out/final-reel.mp4`.

## Локальный запуск

```bash
npm install
npm run studio
npm run render
```

Исходники видео и файлы TT Carvist исключены из Git, чтобы случайно не публиковать личные материалы.
